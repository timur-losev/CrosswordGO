# Screenshots For Project README

Put window/gameplay screenshots into this folder and then run:

```bash
python Utils/WorldChef/generate_project_readme.py
```

Recommended filenames:

- `qt_generator_main.png`
- `qt_generator_hidden_words.png`
- `qt_generator_debug_menu.png`
- `runtime_main_gameplay.png`
- `runtime_gold_line_visuals.png`

The generator auto-embeds any image from this folder (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`) into the root `README.md`.
